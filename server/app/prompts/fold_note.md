# Step: Fold a note into a look's description
<!-- Inputs: <description> (what to draw of one character or place) and <note> (what a person asked to change when it was redrawn). Output: FoldedNote. A person's redo notes were added to the end of the description one after another, for good, so it grew and came to contradict itself ("brown hair ... red hair ... no, darker") in every picture and clip that reads it (13 Nov audit; Reed: "fix everything"). -->

Rewrite <description> so that it already says what <note> asks: one description of who or what to draw, as it now stands.

- Where the note changes something the description says (hair, age, build, clothes, a prop, the light), the note wins and the old words go.
- Everything the note leaves alone stays, in the description's own words and order.
- Only what to draw: no mention of a note, a change, "now" or "instead".
- A note that asks for nothing lasting ("try again", "better") changes nothing: give the description back as it is.
- Never longer than the description and the note together.
