# Desks: where your critiques and questions go (one page)

| You have… | Where you say it | Where it ends up |
|---|---|---|
| A critique of one style's videos | a **Desk – <style>** workspace, first message `/desk Movie` (or UGC, Disney Pixar…) | that desk's file, which the lead reads |
| A critique of the site (screens, wording, speed) | **Desk – Site**, first message `/desk Site` | the Site desk file → the lead's polish list |
| A new rule ("from now on…") | any desk | desk file as DECISION → the lead records it in ops/DECISIONS.md |
| A question ("how does X work?") | a new **Ask – <topic>** workspace | nowhere, unless it becomes a decision |
| "Do this next" | the **LEAD** chat | the lead's NEXT list |

- One desk per style. Go back to the same desk each time; it remembers through its file.
- Desks talk and write things down; they never build, merge or spend. The lead does that.
- Desk files: `sanaa/.context/team/desks/<style>.md`. Each has OPEN (for the lead), Notes and Done.
- Close a desk when its style is finished. Its file stays.
- Models: Opus for the lead and desks; Sonnet for Ask chats and the babysitter.
