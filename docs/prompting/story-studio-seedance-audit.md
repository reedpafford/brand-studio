# Seedance workflow audit — 2026-09-28

Source: [BytePlus Seedance 2.5 prompting guide](https://ai.byteplus.com/resources/how-to-write-better-seedance-2-5-prompts), read in full. This is a code/workflow audit, not a live output-quality evaluation. BytePlus guidance does not establish every Higgsfield control or guarantee generation accuracy.

## Findings and implementation

| Operation | Finding / disposition |
| --- | --- |
| Vision intake | Fixed 3D style, optional cast and reference video, creator-selected duration and aspect ratio are already carried into planning. |
| Reference analysis | Local sampled frames supply staging evidence; the analyzer marks inferred movement and unverified audio. This can miss a rapid gesture or cut. It is not full audiovisual viewing. |
| Ingredients | Stable keys, explicit scopes, identity dependencies and actual image inspection already exist. Keep their purpose separate from shot instructions. |
| Reference export | Numbered files, displayed images and per-shot image tags share one manifest. Upload order resets for each generation. The creator still binds actual mentions in Higgsfield. |
| Prompt opening | Changed from a style/rules block to the story idea, followed by style and reference roles. |
| Prompt density | Removed mandatory-sounding coverage of every camera/material/lighting field. Optional fields should add necessary information only. |
| Prompt ending | Consolidated essential identity, speech and style constraints at the end. Upload instructions remain in the handoff instructions rather than the generation prompt. |
| Timing | Existing schema enforces continuous integer boundaries and selected total runtime. No automatic split by location; one generation may contain several shots. |
| Dialogue | Application inserts saved words with their assigned speakers, once and in order. That is an input guarantee, not a guarantee that the video model performs them correctly. |
| Storyboard preview | Changed new preview instructions to simple line art with minimal color. Each preview has three sequential panels. Updated UI explains that scene edits affect prompts but preview images are not sent to Higgsfield. |
| Storyboard edits | Added the same directing rules to targeted scene revision. Existing code preserves edited actions against reviewer replacement, retains dialogue/timing and invalidates the previous handoff. |
| Unsupported references | Added rejection of video/audio mentions in the current image-only handoff. Source analysis does not attach the original video. |
| Cache | Incremented prompt-review version so the next rebuild does not reuse older prompt reviews. Existing saved packages remain unchanged until rebuilt. |

## Storyboards versus keyframes

The current path is **planning preview → edited scene instructions → image-ingredient handoff**. It is not keyframe generation. BytePlus distinguishes loose multi-panel plot guidance from separate ordered keyframe inputs; its storyboard recommendation is fewer than 15 panels. Our three-panel previews fit that size but are not currently generation inputs.

Do not automatically upload every preview as another ingredient. A future explicit keyframe option needs independent images, ordering, clear reference roles, transition descriptions and a matching export manifest. It should be tested separately; mixing it into the current identity/prop references would change their meaning.

## Remaining limitations and test

- Semantic consistency is model-reviewed, not mechanically proven. Correct numbering cannot prove the model used the right face, action or camera move.
- Keep exact action intent and speaker assignment as the acceptance criteria. Judge a generation against the approved scene plan, not only visual polish.
- For a controlled comparison, rebuild one existing handoff with its existing ingredients and compare the resulting prompt before spending video credits. Then test the same sequence/settings against the prior output. Check entrances, prop interaction, reactions, screen reveal, speaker ownership and the ending.
- A cloud move does not change these creative rules. No hosting or account changes were made during this audit.
