# Basics audit, 2026-10-25 (main at ed1003a)

Reed: "we keep missing basics". Every object in the app was checked against five things: create, edit, delete or archive, undo, and search or filter. Every server route was then checked against what `web/src` calls.

**Priority:**
- **P1** blocks daily work or loses work.
- **P2** is a real friction.
- **P3** is nice to have.

**Who:** Owner is Reed; Editor is the team.

## Objects with no gaps
- **Characters, places, props:** create, edit, archive and unarchive, delete for good, earlier versions with restore, and search.
- **Invites:** invite, copy a new link, cancel.
- **Script versions (variations):** write, edit, approve, undo approval, earlier texts, remove.
- **Cast slots:** add, rename, lock and unlock, remove (only Read the cast is missing, #10).
