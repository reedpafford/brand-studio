# Iron Paws song ads, round 2: lyrics for Reed's OK

Built from Reed's three scripts. Each keeps its story, key lines and claims, with Iron Paws named in the last lines. Reed: the references "should not be weighed very heavily", so the creative comes from the scripts.

The sound is Reed's laid-back pop with a female vocal, varied per song so the three don't sound alike. Each song is about 260–300 sung words, which should come to roughly 2:00–2:20.

Every style line gets Suno's add-on: ", vocals start immediately, no instrumental intro, no instrumental breaks, continuous singing, tight ending".
