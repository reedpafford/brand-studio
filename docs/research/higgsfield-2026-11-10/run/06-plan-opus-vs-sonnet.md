# The one-pass plan on two models: Opus 5.5 and Sonnet 5.5 (10 Nov)
The same prompt (`prompts/one_pass.md` with the rules, the producer craft, the Dialogue and Movie guides and the Omni notes) and the same script (scenes 2-5 of the Palace Guard drama, `06-plan-script.txt`) were given to each model once, through this workspace's own assistant, not the site. This was the prompt's first run on real models. Both plans are beside this file.

| | Opus 5.5 | Sonnet 5.5 |
|---|---|---|
| Fits the site's plan format | Yes | Yes |
| Every spoken line once, in order, by number | Yes (12 of 12) | Yes (12 of 12) |
| Clips | 8, 8-15 s each | 8, 9-15 s each |
| Length | 99 s | 104 s |
| People to draw | 5 | 5 |
| Places to draw | 4 (store, checkout, kitchen, lot) | 2 (store, lot): the kitchen got no picture |
| Whole run | about 2 minutes | about 1.5 minutes |

- Both open on the staring man over Paige's shoulder with her first thought, hold the product for the parking lot, and split the lot scene at the same beats (the open door, the pin, the siren, the plate).
- Both write actions as what the body does ("her jaw trembles", "her throat working") and give voice-over lines as lips closed.
- Opus is a little more thorough (all four places, slightly sharper reasons). Sonnet's hand-offs between clips are as clean.
- Higgsfield made the same scenes as 6 clips because its model takes 24 seconds a clip; Omni's 15-second limit makes ours 8.

One script is one sample: it shows Sonnet can do this job, not that it always matches Opus.
